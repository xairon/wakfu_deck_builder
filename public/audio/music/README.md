# Musique de fond de la table

Dépose ici tes fichiers audio (`.mp3` / `.ogg`) **dont tu détiens les
droits**, puis liste-les dans `manifest.json` :

```json
["combat-theme-1.mp3", "combat-theme-2.ogg"]
```

Le bouton « ♫ Musique » apparaît alors sur la table de jeu (lecture en
boucle mélangée, volume discret, préférence mémorisée).

⚠ Les musiques du MMO Wakfu (et toute bande-son commerciale) sont protégées
par le droit d'auteur — ne les commite pas dans le dépôt et ne les déploie
pas publiquement sans licence d'Ankama. Ce dossier est prévu pour un usage
local/privé ou pour des pistes libres de droits (CC0, CC-BY…).
